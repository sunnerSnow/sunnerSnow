## 💼 工作表現 | Work

在一家財經資訊公司負責以下兩個產品，從需求、設計、開發、測試到部署，大部分由我一人完成，少數由同事支援。

### 財經文章網站｜Next.js
台美股新聞、產業分析和教學文章的閱讀網站。2026 年 3 月接手同事建好的初版，之後的功能大部分由我一人完成。
- **付費牆與影音專欄**：需求規格、視覺規格到實作（預覽段落、模糊遮罩、訂閱引導、訂閱者專屬頁面）
- **會員統一登入**：網站和商城共用同一套登入
- **SEO**：文章頁伺服器渲染、完整 sitemap、canonical、結構化資料、舊站網址對照、無障礙名稱
- **數據與效能**：GA4 事件埋點、GTM、圖片優先載入、可變字型
- **自動部署**：GitLab CI/CD，自動檢查、部署測試機，健康檢查沒過自動回滾

### 財經資訊 App｜React Native + Expo（iOS／Android）
2026 年 8 月從零建立，把網站內容帶到手機原生 App。
- **六個分頁**：新聞、影音（YouTube）、Podcast（App 內播放器）、課程中心、資料庫、關注收藏
- **閱讀體驗**：文章樣式和官網一致，可調字級、站內搜尋、收藏
- **課程中心**：月曆課表和講座報名
- **其他**：會員登入、Firebase／GA4 埋點、EAS 雙平台建置

### 🎨 設計
- 付費牆視覺規格與設計 token
- App 版影音專欄設計稿（附操作導覽影片），並同步修正網站版設計稿
- 課程中心：把需求文件整理成正式規格書，並做出可點擊操作的互動設計稿
